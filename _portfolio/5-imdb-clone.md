A web application built for the CSE216 Database Sessional course at BUET. It recreates most of the core features of IMDB for movie, TV and celebrity content.

As the course required, all data access uses raw Oracle SQL, including functions and triggers, instead of Django models.

**Tech:** Oracle, Django, HTML, CSS, Bootstrap
